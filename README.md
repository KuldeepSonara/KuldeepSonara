## What I Have Shipped

**Live Call Analytics Module**
Real-time per-call sentiment scoring, intent detection, 
confidence metrics, and AI-driven agent suggestions — 
delivered mid-call without interrupting the voice session. 
Built on LiveKit + SIP + Twilio.

**Post-Call Analysis (PCA) Pipeline**
Every call transcript auto-processed by AWS Bedrock Nova 
Pro after hang-up. Structured summaries, sentiment trends, 
and operational insights surfaced on a supervisor dashboard.

**Nova Sonic Speech-to-Speech Deployment**
End-to-end voice AI on AWS ECS Fargate via Vonage API. 
Customers complete service bookings through natural 
conversation during live calls. Multi-tenant routing, 
multi-agent Nova Pro orchestration, live transcription 
via AWS Transcribe.

**Multilingual IVR System**
Dynamic, multi-language IVR on Amazon Connect and Amazon 
Lex with configurable voice tones and sub-menu support. 
Migrated 5 AI bots from Claude 2.1 to Amazon Nova Pro — 
30% improvement in response accuracy.
